# 复盘记录模板

复盘的价值不在于「我今天又亏了」，而在于分辨：**这次是判断错了，还是判断对了但执行错了**。这两种错的改法完全不同。

下面这张表是固定结构，每笔交易填一遍。字段不多，但每一项都必须能填出具体内容——填不出来，说明这笔交易本来就不该做。

## 单笔交易记录

| 字段 | 要填写什么 | 反例（填了等于没填） |
| --- | --- | --- |
| 日期 / 品种 / 周期 | 明确到看的是哪个周期的图 | 只写「黄金」 |
| 当时的市场状态 | 趋势 / 区间 / 不确定 | 「感觉要涨」 |
| 入场依据 | 引用了哪个具体位置或结构 | 「形态不错」 |
| 止损位置 | 具体价格 + 为什么是这里（哪个结构失效） | 「亏 20 点走」 |
| 目标位置 | 前一段推进的等距离目标，或区间对面边界 | 「看情况」 |
| 计划仓位 | 这笔最多亏账户的多少比例 | 「先上一点」 |
| 离场结果 | 是止损、是目标减仓、还是结构破坏离场 | 「平掉了」 |
| 事后判断 | 判断对了 / 判断错了 / 判断对但执行错 | 「运气不好」 |

最后一行是关键。三种结论对应三种改进方向：

- **判断错**：回去看的是「状态识别」和「关键位置」，往读图能力上补。
- **判断对但执行错**：问题在纪律，止损被移动、仓位超计划、提前离场。这类问题改起来最快，也最容易反复。
- **判断对且执行对，仍然亏**：这不是错误，是概率的一部分。不要把正常亏损记成失误，否则会开始怀疑本来正确的方法。

## 每周汇总看三个数

单笔记录容易陷进细节，每周拉一次汇总：

1. **计划止损被移动过几次**：这个数应该趋近于 0，否则先停手。
2. **亏损单的平均亏损 / 盈利单的平均盈利**：不要求倍数很高，但亏损端必须稳定。
3. **「不确定」状态下的交易占比**：越高说明你在强行找机会。

## 一个使用习惯

下单前先填前三行（状态、依据、止损），成交后再补后面的。这个顺序本身就是一道过滤器：很多一时冲动的单子，在写「止损为什么放这里」这一步就写不下去了。

写完别只存着，隔一周重读——当时觉得很充分的理由，一周后往往一眼能看出漏洞。
