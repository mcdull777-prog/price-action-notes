# 怎么练才不白练

大部分人练了很多年，水平停在「说起来都懂，做起来都不对」。问题不在方法，在练法——把「看盘」当成「看图」，把「学习」当成「收藏」。

## 先做减法：一次只练一件事

同时练「趋势识别 + 入场时机 + 止损设置 + 仓位管理」，等于什么都没练。因为错了你不知道错在哪一步。

推荐顺序，每个阶段只盯一个变量：

1. **只判断状态**：每天挑三张图，只写「趋势 / 区间 / 不确定」，不看后面的走势。
2. **只找关键位置**：同一批图，只标出区间边界和最近的有效高低点。
3. **只看力度**：只描述「这一段推进有没有衰减」，不给结论。
4. **才轮到入场和止损**：前三步做稳了，入场点位自己会掉出来。

## 用历史图而不是实时图

实时图有个致命问题：它不给你「不知道」的自由。行情走完你才知道当时该怎么做，但盘中永远在催你做决定。

做法很简单：把图表往左拉，遮住右边，一根一根往右推。每推一根，先写下判断，再揭开下一根看对不对。

这一步的价值在于**记录你的判断**。判断对了是运气还是逻辑，只有写下来才能分辨。

## 复盘要记「当时怎么想」，不是「后来怎么走」

大多数人复盘只记结果：赚了、亏了、多少点。这种记录一年后还是一团模糊。

要记的是决策过程。用一张固定表就够了，我把它单独放在 [复盘记录模板](/notes/review-template)。四个必填项：

- 入场时的状态判断（趋势 / 区间 / 不确定）
- 入场依据引用了哪个关键位置
- 止损为什么放在那里，失效的定义是什么
- 离场时发生了什么，和当初预期差在哪

## 一条别忽略的及格线

模拟盘练够一段时间后，检查一件事：**你的亏损是不是可控的**。

如果每次亏都是「超出计划」的亏——扛单、加仓、改止损——那说明问题根本不在读图，在执行纪律。这种情况下继续练形态没有任何意义，先把「止损不许动」这一条做到，再谈技术。

## 关于「多久能稳定」

我不给时间承诺。但有个观察是可靠的：**能稳定说出「这段我看不懂，所以不做」的人，通常比能画出十个形态的人活得更久**。

练习的目标不是让自己对每一段行情都有观点，而是让自己只在那少数看得懂的段落下注。
